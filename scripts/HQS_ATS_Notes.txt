  SECTION 4 — HOW THE SYSTEM WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ── 4.1  DATA FLOW ────────────────────────────────────────────────────────────

  Step 1:  User clicks / submits form / drags card
  Step 2:  Component calls dispatch({ type: 'ACTION', payload: data })
  Step 3:  AppContext reducer() creates new state object
  Step 4:  All components re-render with updated data
  Step 5:  useEffect → saves JSON to localStorage automatically

  20 Action Types:
    Jobs        → ADD_JOB | UPDATE_JOB | DELETE_JOB
    Candidates  → ADD_CANDIDATE | UPDATE_CANDIDATE | DELETE_CANDIDATE
                  MOVE_CANDIDATE_STAGE | ADD_NOTE | DELETE_NOTE | UPDATE_RATING
    Interviews  → ADD_INTERVIEW | UPDATE_INTERVIEW | DELETE_INTERVIEW
    Team        → ADD_TEAM_MEMBER | UPDATE_TEAM_MEMBER | DELETE_TEAM_MEMBER
    Templates   → ADD_TEMPLATE | UPDATE_TEMPLATE | DELETE_TEMPLATE
    Settings    → UPDATE_SETTINGS

  localStorage key: "hqs_ats_state"
  Data survives page refresh automatically.
  Reset: Settings → "Reset to Demo Data"


  ── 4.2  RESUME AUTO-FILL PIPELINE ────────────────────────────────────────────

  Stage 1: Drop File
    → ResumeDropzone.jsx detects file type (.pdf / .docx / .doc)

  Stage 2: Text Extraction
    PDF  → pdfjs-dist reads each page → joins all text
    DOCX → mammoth converts Word XML → raw plain text

  Stage 3: Field Detection (resumeParser.js)
    Field          Method
    ─────────────────────────────────────────────────────────
    Email        → Regex: name@domain.com
    Phone        → Regex: +95 9... / 09... / international
    Name         → Scan first 15 lines for "Firstname Lastname" pattern
    Location     → Myanmar city names + generic City, Country
    LinkedIn     → Regex: linkedin.com/in/...
    Skills/Tags  → Keyword scan: Forklift, QC, GMP, ISO, MS Office...
    Experience   → "X years experience" phrase → tag

  Stage 4: Auto-Fill Form
    → Fields highlighted GREEN with "✓ auto-filled" label
    → Banner: "6 fields auto-filled from resume"
    → Skills merged into tags (no duplicates)
    → All fields remain editable before saving

  Dropzone States:
    idle      → Dashed gray border, upload icon
    dragging  → Blue border, scale animation
    parsing   → Spinner + animated progress bar
    success   → Green border, field preview summary
    error     → Red border, error message, retry link


  ── 4.3  KANBAN PIPELINE — DRAG & DROP ────────────────────────────────────────

  7 Stages:
    Applied → Screening → Interview → Medical Check →
    Offer Sent → Deployed → Rejected

  Library: @dnd-kit/core + @dnd-kit/sortable

  How it works:
    1. DndContext wraps all 7 column components
    2. Each card = SortableItem (useSortable hook)
    3. Each column = Droppable zone (useDroppable hook)
    4. PointerSensor activates after 5px move (no accidental drags)
    5. DragOverlay shows ghost copy of card while dragging

  After drop:
    → onDragEnd finds source + target stage
    → Dispatches MOVE_CANDIDATE_STAGE
    → candidate.stage updated
    → Timeline entry added: { stage: "Interview", date: "2026-10-12" }
    → localStorage auto-saves

  Click-to-Move (alternative on Candidate Detail page):
    → Click any stage on the stage bar to instantly move candidate
    → Current stage = blue  |  Past stages = green

  ── 6.1  WHAT IS AN API? ─────────────────────────────────────────────────────

  API = Application Programming Interface
  It lets your app talk to another service (AI, database, email, etc.)
  You send a REQUEST → The service sends back a RESPONSE (usually JSON)


  ── 6.2  HOW TO CALL AN API IN REACT ─────────────────────────────────────────

  Method 1: Using fetch() (built into browser — no install needed)

    async function getCandidates() {
      const response = await fetch('https://api.example.com/candidates')
      const data = await response.json()
      return data
    }

  Method 2: POST request (sending data)

    async function addCandidate(candidateData) {
      const response = await fetch('https://api.example.com/candidates', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'Authorization': 'Bearer YOUR_API_KEY'
        },
        body: JSON.stringify(candidateData)
      })
      const result = await response.json()
      return result
    }

  Method 3: Using axios (easier, install with: npm install axios)

    import axios from 'axios'

    const response = await axios.get('https://api.example.com/candidates')
    const data = response.data


  ── 6.3  OPENAI API — AI RESUME PARSING ──────────────────────────────────────

  Use OpenAI to intelligently parse resumes (much smarter than regex).

  Website:  https://platform.openai.com
  Get API Key:
    1. Go to https://platform.openai.com/api-keys
    2. Click "Create new secret key"
    3. Copy the key — save it! (shown only once)

  Install SDK:
    npm install openai

  Example — Parse resume text with AI:

    import OpenAI from 'openai'

    const openai = new OpenAI({
      apiKey: 'sk-your-api-key-here',
      dangerouslyAllowBrowser: true   // only for dev/testing
    })

    async function parseResumeWithAI(resumeText) {
      const response = await openai.chat.completions.create({
        model: 'gpt-4o-mini',         // cheap + fast model
        messages: [
          {
            role: 'system',
            content: `You are a resume parser. Extract information from the 
                      resume text and return ONLY valid JSON with these fields:
                      firstName, lastName, email, phone, location, 
                      linkedIn, skills (array), yearsExperience`
          },
          {
            role: 'user',
            content: `Parse this resume:\n\n${resumeText}`
          }
        ],
        response_format: { type: 'json_object' }   // forces JSON output
      })

      const parsed = JSON.parse(response.choices[0].message.content)
      return parsed
    }

  Cost estimate:
    gpt-4o-mini:  ~$0.15 per 1 million input tokens
    1 resume ≈ 500-1000 tokens
    Parsing 1000 resumes ≈ $0.08–$0.15 (very cheap!)


  ── 6.4  ENVIRONMENT VARIABLES (Keep API keys secret) ────────────────────────

  NEVER put API keys directly in your code files!
  Use .env files instead:

  Step 1: Create .env file in project root:
    VITE_OPENAI_API_KEY=sk-your-key-here
    VITE_API_BASE_URL=https://api.example.com

  Step 2: Add .env to .gitignore:
    echo ".env" >> .gitignore

  Step 3: Use in your code:
    const apiKey = import.meta.env.VITE_OPENAI_API_KEY
    const baseUrl = import.meta.env.VITE_API_BASE_URL

  IMPORTANT: All Vite env variables MUST start with VITE_


  ── 6.5  BACKEND API OPTIONS ─────────────────────────────────────────────────

  If you want a real database (not localStorage), choose a backend:

  Option A: Supabase (easiest — free tier available)
    Website:  https://supabase.com
    What:     PostgreSQL database + auto-generated REST API
    Install:  npm install @supabase/supabase-js

    Example:
      import { createClient } from '@supabase/supabase-js'

      const supabase = createClient(
        'https://your-project.supabase.co',
        'your-anon-key'
      )

      // Get all candidates
      const { data, error } = await supabase
        .from('candidates')
        .select('*')

      // Add candidate
      const { data, error } = await supabase
        .from('candidates')
        .insert({ firstName: 'Aung', lastName: 'Myint', email: '...' })

  Option B: Firebase (Google — free tier available)
    Website:  https://firebase.google.com
    Install:  npm install firebase

  Option C: Node.js + Express (build your own)
    npm install express cors mongoose   (for MongoDB)
    Or: npm install express cors pg     (for PostgreSQL)

  Option D: Airtable (spreadsheet-style database)
    Website:  https://airtable.com
    Good for: Small teams, non-technical users


  ── 6.6  EMAIL API (Send emails from app) ────────────────────────────────────

  Option A: SendGrid (most popular)
    Website:  https://sendgrid.com (free: 100 emails/day)
    Install:  npm install @sendgrid/mail

    Example:
      import sgMail from '@sendgrid/mail'
      sgMail.setApiKey(import.meta.env.VITE_SENDGRID_KEY)

      await sgMail.send({
        to: 'candidate@example.com',
        from: 'recruitment@hqs.com.mm',
        subject: 'Interview Invitation',
        text: 'Dear Aung, you are invited for an interview...'
      })

  Option B: EmailJS (works directly from browser — no backend needed!)
    Website:  https://emailjs.com (free: 200 emails/month)
    Install:  npm install emailjs-com
